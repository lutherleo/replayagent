# Data

replayagent downloads no datasets. Everything below is committed and was written or
generated in this repository.

| Data | Path | Source | License |
|---|---|---|---|
| Research corpus: 10 short markdown documents on durable execution topics (event sourcing, replay, retries, timers, idempotency, versioning, SQLite durability, sagas, human-in-the-loop, agent tool calling) | `src/replayagent/examples/research/corpus/*.md` | written for this repository | MIT (this repo) |
| Golden histories recorded by the research agent with the deterministic fake model, before (`v0`) and after (`v1`) the citation check was added | `tests/golden/research_v0.json`, `tests/golden/research_v1.json` | generated by `scripts/make_golden.py` (`make golden GOLDEN=research_v1`) at commits `57e680b` (v0, before the citation check) and `934c7be` (v1) | MIT (this repo) |

All LLM outputs used in tests and in `make demo` come from the scripted fake responder
(`src/replayagent/examples/research/fake_llm.py`); they are synthetic. The only real-model
output in the repository is the sample pasted in the README from one `make demo-ollama`
run against a local `llama3.1:8b`.
